Set it up in Gmail (rallings@enotri.ca)

  1. Open this page in Chrome. Click Copy Version A.
  2. In Gmail on a computer: ⚙ Settings → See all settings → General → Signature → Create new. Name it "Enotri full". Paste.
  3. The photo and banner won't paste (they're files on your Mac). Delete each broken image, then Insert image → Upload: sig-photo-96.png and sig-banner-320.png from this folder. Pick Original size if asked.
  4. Create a second signature, "Enotri reply", and paste Version B.
  5. Under Signature defaults: new emails → Enotri full; reply/forward → Enotri reply. Tick "Insert signature before quoted text…".
  6. Save Changes. Then stop typing the old sign-off by hand, or it will appear twice.
  7. Gmail app: leave Mobile signature off; if phone emails show no signature, paste the plain-text version.
  8. Test: send one email to yourself and one to another address; check on phone and computer.
